Interactive Shiny app for exploring and validating South African mortality data (1997-2022)
Published

January 23, 2026

1 Overview

This interactive Shiny application provides comprehensive exploration of the South African vital registration mortality data spanning from 1997 to 2022. It is designed for rapid data quality checks and exploratory analysis.

2 Two Versions Available

2.1 🚀 Lite Version (Deployable)

  • File: app_lite.R
  • Uses pre-aggregated summary data (~14 MB without full cross-tab)
  • Loads in seconds
  • Safe for deployment to shinyapps.io
  • No individual-level records exposed

2.2 📊 Full Version (Local Only)

  • File: app.R
  • Uses complete mortality microdata (~3 GB)
  • 13.1 million individual records
  • Full filtering and raw data browsing
  • Requires local data access

3 Features

The Data Explorer includes the following analysis modules:

3.1 📊 Overview

  • High-level summary statistics
  • Deaths over time (weekly trends)
  • Distribution by province and age group
  • Filter by year range, province, death type, and cause type

3.2 📅 Temporal Trends

  • Weekly, monthly, and yearly aggregation options
  • Seasonality heatmaps
  • Year-over-year comparison
  • Optional year overlay comparison

3.3 🏥 Cause Codes

  • Top N underlying causes analysis (ICD-10)
  • Cause trends over time
  • Cause distribution by province
  • Detailed cause code table with demographics

3.4 👥 Demographics

  • Age distribution histograms
  • Sex distribution pie charts
  • Age-sex population pyramids
  • Registration delay analysis

3.5 🗺️ Geographic

  • Provincial mortality distributions
  • Top districts analysis
  • Provincial trends over time

3.6 📋 Raw Data

  • Browse filtered data samples
  • Download filtered datasets as CSV
  • Column filtering and search

4 Data Source

  • Dataset: Deaths2022_MRCversionFINAL.feather
  • Records: ~13.1 million death records
  • Time Period: 1997-2022
  • Variables: 57 columns including demographics, cause codes, geographic identifiers, and timing information

5 Interactive App

NoteData Privacy

The raw mortality data is hosted securely on ShinyApps.io and is not available in the GitHub repository. The app requires authentication for access to detailed individual-level data.

WarningApp Not Yet Deployed

The embedded app will appear here once deployed to ShinyApps.io. If you see a “Not Found” error above, please run the deployment commands below.

6 Run Locally

Lite Version (recommended for quick exploration):

shiny::runApp("projects/data_explorer/app_lite.R")

Full Version (requires local data files):

# Install required packages if needed
install.packages(c("shiny", "bslib", "arrow", "data.table", 
                   "plotly", "DT", "labelled", "here", "sf",
                   "waiter", "shinycssloaders"))

# Run the app
shiny::runApp("projects/data_explorer/app.R")

Or from the project directory:

cd projects/data_explorer
Rscript -e "shiny::runApp('app_lite.R')"  # Lite version
Rscript -e "shiny::runApp('app.R')"        # Full version

9 Technical Notes

  • Uses plotly for interactive visualizations
  • Built with bslib for modern Bootstrap 5 theming
  • Data loaded via arrow/feather for fast I/O
  • data.table for efficient in-memory operations
  • Large dataset (~13M rows) - initial load may take 5-10 seconds
