1 What this is

A single reference table answering, for each Notifiable Medical Condition (NMC) — South Africa’s IDSR-aligned notification list — the question: “if this condition were the underlying cause of death, what ICD-10 and ICD-11 code should be assigned?” Alongside the verified UCoD (underlying cause of death) ICD-10 and ICD-11 codes, the table lists known coding pitfalls and how the condition tends to actually appear (or not) in MACOD vital-registration data.

Use the search box or per-column filters below to find a condition, category, or ICD code. Columns wrap long text — click a cell to expand, or use the CSV / Excel buttons to export the full table.

Note

This table is generated from the SA NMC ICD Reference (v3) and rebuilt by nmc_icd10_verifier/build_verified_nmc_table.R. It is also used as the source map for the NMC & MACOD Comparison project, where the counts and MACOD sensitivity analysis derived from this map are presented.

2 Definitions & cause-of-death coding

Medical certification of death (the WHO/MCCD form) records causes in a structured sequence, and only one cause per death is coded as the statistic used in mortality reporting.

Term Definition
Underlying cause of death (UCoD) “The disease or injury which initiated the train of morbid events leading directly to death.” This is the single cause selected for national/international mortality statistics (WHO ICD-10/ICD-11 rules), and is the code shown in the UCoD ICD-10 / UCoD ICD-11 columns below.
Immediate cause of death The final disease or condition directly causing death (death certificate Part I(a)) — e.g. “septic shock” — which is usually a consequence of the underlying cause, not the underlying cause itself.
Antecedent / intervening causes Conditions reported in Part I(b)/(c) that link the immediate cause back to the underlying cause (the causal chain).
Multiple cause of death (MCOD) coding All conditions listed on the certificate (Part I chain and Part II contributory conditions) are coded, not just the UCoD. MCOD analysis can reveal a notifiable condition even when it was not selected as the UCoD (e.g. HIV listed as a contributory cause under a UCoD of TB).
Part II — contributory conditions Conditions that contributed to death but were not part of the direct causal chain to the immediate cause (e.g. diabetes, hypertension). These are coded but never selected as UCoD.

Why this matters for NMC ↔︎ MACOD linkage: the NMC/MACOD comparison and sensitivity tables in this site match on the UCoD only — the single cause South Africa’s vital statistics report. A notifiable condition that is frequently recorded as an immediate or contributory cause (rather than the UCoD) will therefore appear under-captured in MACOD, even if it was mentioned on the death certificate. This is a key reason capture ratios in the NMC & MACOD Comparison sensitivity analysis fall below 100% for some conditions — the coding pitfall columns below flag where this is a known issue.

For each row: UCoD ICD-10 / UCoD ICD-11 are the codes to assign when this NMC condition is the underlying cause of death. The Likely immediate-cause / miscode ICD-10s column lists specific proxy codes that tend to appear in MACOD instead — i.e. what the death is actually coded as when the notifiable condition is not correctly identified/documented as the UCoD (e.g. Measles deaths often carry an immediate cause of J18.9 “pneumonia, unspecified” rather than the measles-specific code).
